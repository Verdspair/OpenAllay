# Fabric 26.2 content profile

This opt-in development profile broadens OpenAllay’s real-game capability
surface without adding runtime dependencies to the shipped mod.

The source of truth is
[`scripts/dev-content-profile.json`](../../scripts/dev-content-profile.json).
Every entry was resolved from the Modrinth v2 project-version API using both
`loaders=["fabric"]` and `game_versions=["26.2"]` on 2026-07-25, downloaded
from its returned CDN URL, and verified locally against the retained SHA-256.

## Coverage

- Farmer’s Delight Refabricated and two Delight add-ons exercise large,
  overlapping ingredient and cooking-recipe catalogs.
- Crate Delight and Storage Delight exercise container comparison and
  least-material recipe tasks.
- CC: Tweaked adds a substantially different registered-content and command
  surface.
- JEI and REI, with their required public dependencies, exercise both
  first-party recipe-viewer Extensions in one Fabric environment.

Fabric API is supplied by the normal development runtime and is therefore not
duplicated in the profile directory.

## Installation

The installer writes only the exact named artifacts into the ignored Fabric
development `mods` directory and refuses checksum mismatches:

```bash
scripts/install-dev-content-profile.sh install
scripts/install-dev-content-profile.sh verify
```

Set `OPENALLAY_CONTENT_MODS_DIR` to use another isolated test instance. The
script does not remove unrelated mods and does not launch Minecraft.

This retained manifest is compatibility evidence, not a claim that a graphical
or live-provider test has run. Real-client and billable benchmark runs remain
explicit opt-in operations.
