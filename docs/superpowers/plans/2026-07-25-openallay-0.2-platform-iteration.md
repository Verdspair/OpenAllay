# OpenAllay 0.2 Platform Iteration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the OpenAllay 0.2 line a measurable Agent platform with
always-available core JavaScript literacy, vertical Skills, installable Skill
and Extension communities, automatic server models, focused world observation,
and a reusable benchmark.

**Architecture:** One Java-owned capability descriptor graph drives Rhino,
system-prompt schema, Extension settings, and typed results. Skills and
Extensions use separate versioned catalogs and atomic local publication;
server models and spatial observations remain connection/request scoped.

**Tech Stack:** Java 25, Minecraft 26.2, KubeJS Rhino, Gson, JDK HTTP client,
Brigadier, JUnit 5, Fabric, NeoForge, GitHub Actions.

`content-profile` nor `inventory-rich`, so the food-ranking and
recipe/craftability cases were silently excluded. The fixture now carries
detached food properties, an exact recipe, and a matching inventory, and the
offline benchmark command includes a regression guard proving that both cases
remain selected. The server-model case now uses a separate
`server-model-routing-v1` fixture that drives a real `GuideService` request,
captures the server selection, and verifies that the response stays in the
same session; it is no longer mislabeled as a JavaScript Agent case. Selection
reports distinguish fixture mismatch from a missing capability. No new
provider or graphical E2E run was performed for these repairs.

The live runner now accepts `--profile <models.json>`, optional
`--profile-id`, `--repeats`, `--cases`, `--include-commands`, and `--output`.
It resolves the production schema-2 profile through its environment credential
reference and retains the profile ID plus canonical model ID in a schema-3
report. Direct environment-variable configuration remains compatible.
